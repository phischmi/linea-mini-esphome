# Mitschnitte der eigenen Maschine

Hier liegen die **Logs** (`NN_name.log`, erzeugt mit `tools/vcd_to_sniffer_log.py` oder vom ESP32-Sniffer) und je Mitschnitt ein Eintrag unten. Rohdaten (`.sr`, `.vcd`) bleiben lokal und sind per `.gitignore` ausgeschlossen. Anleitung: `docs/guides/sniffer.md`.

Für jeden Mitschnitt eintragen:

| Datei | Datum/Uhrzeit | Szenario | Wasserquelle (Tank / Festwasser) | Solltemp. | Aktionen mit ungefährer Uhrzeit |
|---|---|---|---|---|---|
| _(noch keine)_ | | | | | |

Stand der Firmware (einmal pro Messreihe): Hauptplatine v2.12, IoT-Modul-Gateway v7.4.2 (Angabe des Nutzers; bei Änderung hier aktualisieren).
